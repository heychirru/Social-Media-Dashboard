Social Media Dashboard

A comprehensive analytics platform that aggregates data from multiple social media platforms to provide insights into your social media presence.

Key Features

Multi-Platform Analytics

Aggregate data from Instagram, Twitter/X, and other social media platforms into a unified dashboard for comprehensive insights.

Cross-Platform Search

Search for posts, tweets, and content across multiple platforms simultaneously to find relevant social media content.

User Analytics

Track follower growth, engagement rates, and post performance to understand your audience and optimize your content strategy.

Technology Stack

Java

Backend development with Spring Boot framework

Spring Boot

Rapid application development and microservices

Bootstrap

Responsive and modern UI components

H2 Database

Lightweight in-memory database for development

Supported Platforms

Instagram

Track followers, posts, engagement rates, and recent content performance using the Instagram Basic Display API.

Twitter/X

Monitor followers, tweets, engagement metrics, and search through public tweets using the Twitter API v2.

Getting Started

Quick Setup Guide
  1. Configure API Keys: Visit the Configuration page to set up your social media API credentials.
  2. Search for Users: Use the search functionality to find and analyze social media profiles across platforms.
  3. View Analytics: Access comprehensive dashboards showing aggregated statistics and platform-specific insights.
  4. Monitor Performance: Track engagement rates, follower growth, and content performance over time.
